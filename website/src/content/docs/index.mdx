## The shape

A declaration builds one normalized application schema. From it, Intpot can build a live interface or generate ordinary Python source for a target framework.

```python
from intpot import App

app = App("my-app")

@app.tool()
def add(a: int, b: int) -> int:
    """Add two numbers."""
    return a + b
```

```sh
intpot serve app.py --cli
intpot serve app.py --api
intpot serve app.py --mcp
```
