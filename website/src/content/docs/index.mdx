## One definition, three ways to run

Register typed Python functions with `@app.tool()`. Intpot keeps behavior in one place and serves it through a Typer CLI, FastAPI, or FastMCP interface. Existing apps can also be converted across all six Typer, FastAPI, and FastMCP directions.

```python
from intpot import App

app = App("my-app")

@app.tool()
def add(a: int, b: int) -> int:
    """Add two numbers."""
    return a + b
```

```sh
intpot serve app.py --cli
intpot serve app.py --api
intpot serve app.py --mcp
```
