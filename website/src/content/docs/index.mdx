## One definition, three ways to run

Register typed Python functions with `@app.tool()`. Intpot keeps behavior in one place and serves it through a Typer CLI, FastAPI, or FastMCP interface. Existing apps can also be converted across all six Typer, FastAPI, and FastMCP directions.

```python
from intpot import App

app = App("my-app")

@app.tool()
def add(a: int, b: int) -> int:
    """Add two numbers."""
    return a + b
```

```sh
intpot serve app.py --cli
intpot serve app.py --api
intpot serve app.py --mcp
```

## Try it in your browser

Edit a bounded CLI command, HTTP request body, or MCP tool-call draft, then explicitly preview it locally. Each panel validates its own request and computes a fresh result through one shared browser-local function. This is an interface contract explorer—not Python adapter execution; no server, backend, MCP client, or model is contacted.
